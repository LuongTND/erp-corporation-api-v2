# Docs Conventions

## Naming

- `kebab-case.md` — no number prefix, no SCREAMING_SNAKE, no camelCase
- Examples: `summary.md`, `auth-flow.md`, `rbac-guide.md`

## Structure

```
docs/
  summary.md              # project overview
  <feature>-guide.md      # implementation guide
  <feature>-flow.md       # flow/sequence diagrams
  <feature>-report.md     # analysis/audit output
```
